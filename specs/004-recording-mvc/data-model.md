# Модель даних

## Call

- **Роль**: агрегат моделі й єдина точка застосування правил предметної області для керування записами.
- **Поточні атрибути**: `callId`, `client`, `operator`, `telephonyService`, `state`.
- **Колекція**: `recordings: List<CallRecording>`, множинність `0..*`; узгоджується зі сховищем під час завантаження й після успішних змін.
- **Операції**: прочитати всі записи, додати, виправити або видалити запис.
- **Правила доступу**: зміни заборонені, якщо оператор недоступний або `state` дорівнює `RequestRejected`, `CallFailed`, `QualityEvaluated` чи `SummarySent`; у початковому `NewRequest` за доступного оператора зміни дозволені. Читання не обмежується станом.
- **Помилки**: повертає результат українською без HTTP-коду. Помилка сховища не перетворюється на успіх.

## CallRecording

- **Поля**: `recordingId: String`, `duration: int`, `createdAt: LocalDateTime`.
- **Валідація**: ID заданий і після обрізання пробілів не порожній; `duration >= 0`; `createdAt` заданий.
- **Ідентичність**: `recordingId` унікальний. Під час виправлення він не змінюється та має збігатися з ID у шляху запиту.

## RecordingStore

- **Роль**: абстракція довготривалого збереження, залежність `Call`.
- **Операції**: читання всіх і пошук за ID; окреме додавання без перезапису; оновлення лише існуючого ID; видалення лише існуючого ID.
- **Реалізація**: наявний `SqliteRecordingStore`; єдине місце SQL. Схема `call_recordings(recordingId, duration, createdAt)` лишається без нових таблиць.

## Operation result

- **Роль**: результат дії моделі для контролера й вигляду.
- **Дані**: успіх або українське повідомлення відмови; за потреби — отриманий список чи змінений запис.
- **Категорії відмови**: некоректні дані, дублікат/заборонена зміна, відсутній запис, інфраструктурна помилка. HTTP-код до моделі не належить.

## Відносини

- `Call` агрегує `0..* CallRecording` і працює зі сховищем через `RecordingStore`.
- `SqliteRecordingStore` реалізує `RecordingStore`.
- Контролер звертається до `Call` та передає результат `CallCenterWebView`.
- HTTP-відповідь вигляду містить статус і список або українське повідомлення; її структура зафіксована у [контракті API](contracts/http-api.md).
