# Швидкий запуск і перевірка

## Передумови

- JDK 21 і Maven 3.9 або новіший доступні в `PATH`.
- Команди виконуються з кореня репозиторію в PowerShell.

Перевірте середовище:

```powershell
java -version
mvn -version
```

## Зібрати й перевірити

```powershell
mvn package
```

Очікувано: збірка завершується успішно, проходять автоматизовані перевірки Maven і створюються класи в `target`.

## Запустити сценарій

```powershell
mvn exec:java -Dexec.mainClass=callcenter.Main
```

Очікувано: прототип виводить попередні повідомлення українською в тому самому порядку. Після завершення сценарію існують:

- `target/callcenter.db`
- `target/callcenter-report.html`

Відкрийте HTML-файл у браузері вручну; запуск браузера не є частиною програми. Таблиця має містити заголовки `recordingId`, `duration`, `createdAt` і рядки для всіх записів у базі.

## Перевірити збереження та безпечний звіт

1. Повторно виконайте команду запуску, не видаляючи `target`. База має залишитися, а запис із тим самим `recordingId` має оновитися без дублювання.
2. У тестах збережіть два записи, прочитайте їх через сервіс і перевірте відповідність кількості рядків даним.
3. Перевірте HTML-екранування значеннями, що містять `<`, `>`, `&`, лапки й апостроф: вони мають бути видимі як текст.
4. Перевірте порожню базу: файл звіту створюється із заголовками та порожнім тілом таблиці.
5. Перевірте помилку SQLite/звіту: застосунок виводить українське повідомлення про помилку та не заявляє про успішне збереження чи створення актуального звіту.

Деталі полів і ключа наведені в [data-model.md](data-model.md), контракт команд і артефактів — у [contracts/cli-report.md](contracts/cli-report.md).
