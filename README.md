# Імітаційний прототип кол-центру

Навчальний консольний прототип демонструє обробку заявки на зворотний дзвінок, розмову за сценарієм, створення запису, оцінювання якості та надсилання підсумку. Він призначений для ознайомлення з об'єктно-орієнтованою моделлю, життєвим циклом дзвінка та локальним збереженням даних.

Телефонія та електронна пошта лише симулюються українськими повідомленнями. Застосунок використовує Maven, JDK 21, Google Guice 7 та SQLite; зовнішній сервер бази даних не потрібен.

## Передумови

Потрібні JDK 21 і Maven 3.9 або новіший у `PATH`. Виконуйте команди з кореня репозиторію в PowerShell.

## Зібрати та запустити демонстрацію

```powershell
mvn package
mvn exec:java -Dexec.mainClass=callcenter.Main
```

Успішний сценарій виводить наявні стани `NewRequest`, `CallInProgress`, `Recorded`, `QualityEvaluated`, `SummarySent` у тому самому порядку та повідомляє про завершення демонстрації.

Після успішного виконання створюються:

- база даних `target/callcenter.db`;
- статична таблиця `target/callcenter-report.html`.

Відкрийте `target/callcenter-report.html` у браузері вручну. У порожній базі таблиця має заголовки `recordingId`, `duration`, `createdAt` і не має рядків даних.

Повторний запуск не видаляє попередні записи й не очищає каталог `target`. Повторне збереження того самого `recordingId` оновлює один рядок без дублювання. Не використовуйте `mvn clean` перед перевіркою збереження, бо Maven видалить файл SQLite у `target`.

Якщо підключення, запис, читання або генерація звіту завершується помилкою, застосунок виводить українське повідомлення й припиняє запуск, не заявляючи про успішне збереження чи свіжий звіт.

## Перевірки

Maven-збірка запускає JUnit-перевірки та перевірки життєвого циклу з `src/test/java/callcenter/CallLifecycleChecks.java`.
